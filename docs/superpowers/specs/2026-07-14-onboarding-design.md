# 온보딩 화면 설계

작성일: 2026-07-14

## 목적
첫 실행 사용자에게 ClipNote의 핵심 기능·동작을 슬라이드로 설명해 초기 이해도와 활성화를 높인다. 메뉴에서 언제든 다시 볼 수 있다.

## 트리거
- 최초 실행 1회 자동 표시 + 메뉴("사용법")에서 수동 재열람.
- AsyncStorage 플래그 `clipnote.onboardingSeen`로 최초 여부 판별.
- 진입점(`app/index.tsx`) 마운트 시 플래그를 읽어, 안 봤으면 `router.replace('/onboarding')`. 플래그 읽는 동안 홈 렌더를 보류해 깜빡임을 막는다.

## 화면 형식
- 새 라우트 `app/onboarding.tsx`, 헤더 없는 전체화면.
- 가로 페이징 캐러셀(`ScrollView pagingEnabled`), 4슬라이드.
- 하단: 점(dot) 인디케이터 + 다음/시작하기 버튼. 우상단: 건너뛰기(Skip).
- 마지막 슬라이드에서 버튼 라벨이 "시작하기"로 바뀐다.
- 스타일: 브랜드컬러 `#7C5CFC`, 기존 `lib/theme` 토큰 재사용.

## 슬라이드 내용
1. 환영 — "링크만 붙여넣으면 예쁜 공유 카드" (ClipNote 한 줄 소개).
2. 이렇게 동작해요 — 3스텝: ① URL 붙여넣기 ② 제목·설명·이미지 자동으로 카드 완성 ③ 로그인하면 짧은 공유 링크까지.
3. 이런 것도 돼요 — 인스타·네이버카페처럼 미리보기 안 잡히는 링크도 자동 정리 / 로그인만 하면 어디서든 내 북마크.
4. 공유는 클릭 한 번 — 공유 브릿지 페이지 자동 생성, 설명 안 써도 공유. + "시작하기" 버튼.

## 종료 동작 (건너뛰기·시작하기 공통)
- 플래그 저장(다시 안 뜸).
- `router.canGoBack()`이면 뒤로(메뉴에서 연 경우 원위치), 아니면 `router.replace('/')`(최초 실행).

## 파일
- `app/onboarding.tsx` — 온보딩 화면.
- `lib/onboarding.ts` — 플래그 get/set (AsyncStorage 래퍼).
- `app/_layout.tsx` — onboarding 라우트 등록(headerShown false).
- `app/index.tsx` — 최초 실행 게이트.
- `components/HeaderMenu.tsx` — "사용법" 메뉴 항목 추가.

## 비목표 (YAGNI)
- 슬라이드별 삽화/스크린샷 이미지(추후). 이번엔 텍스트+아이콘 수준.
- 온보딩 A/B, 애니메이션 트랜지션 커스터마이즈.
